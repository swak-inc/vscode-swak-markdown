# Support / サポート

Report bugs and feature requests for Swak Markdown through [GitHub Issues](https://github.com/swak-inc/vscode-swak-markdown/issues).

Swak Markdownの不具合・要望は [GitHub Issues](https://github.com/swak-inc/vscode-swak-markdown/issues) へお願いします。

Include the following information. / 次の情報を添えてください。

- Extension version / 拡張のバージョン
- Editor name and version, OS / エディター名・バージョン・OS
- Reproduction steps and expected behavior / 再現手順と期待する動作
- A minimal Markdown example and screenshot / 最小構成のMarkdownとスクリーンショット

Remove private documents, personal information, credentials, and local paths from public reports. Report security vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/swak-inc/vscode-swak-markdown/security/advisories/new), rather than including exploit details in a public issue.

公開する報告からは、非公開文書・個人情報・認証情報・ローカルパスを除いてください。脆弱性は[GitHubの非公開報告フォーム](https://github.com/swak-inc/vscode-swak-markdown/security/advisories/new)へお願いします。悪用手順などの詳細は公開Issueに記載しないでください。
